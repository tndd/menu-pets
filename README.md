# menu-pets（MenuPup）

メニューバーでAnnoying Dogが走るmacOS用システムモニターです。負荷が高いほど犬が速く動きます。クリックすると横幅256ptのパネルを開きます。

## 起動

macOS 13以降、Swift 6.0以降のCommand Line Toolsが必要です。初回ビルドのみSwiftTermの取得にネットワークを使います。

```sh
./scripts/build.sh
open build/MenuPup.app
```

通常動作でネットワーク通信、管理者権限、アクセシビリティ権限は使いません。ローカル向けのアドホック署名で、Developer ID署名・公証はしていません。

## 操作

- 犬をクリック：パネルの開閉。右クリック：表示モード・設定・終了。
- 歯車の「キャラクター」でA · Classic（ずんぐり）／B · Low Run（横長）を切り替え。選択は保存され、次回起動にも引き継がれます。
- 歯車の「テーマ」からGlass / Material、「外観」からシステム / ライト / ダークを選択できます。
- 3つのメーター：CPU（青）・GPU（紫）・メモリ（オレンジ）。
- バッテリー：過去24時間の残量を15分の区間ごとに表示。薄い格子、充電中の印付き。Glassでもグラフの背景は不透明です。空白は未計測です。
- 最下部：1行目のコマンドをEnterで実行すると、パネルが約0.18秒で横520pt・縦464ptへ広がり、本物のzsh端末を表示します。メーターの大きさは維持し、端末は拡大後の横幅を使います。以後の入力、Tab補完、Ctrl-C、ANSI色表示などは端末内で操作します。
- パネルを閉じると端末セッションを終了し、次回は256×302ptのサイズに戻り、ホームディレクトリの新しいセッションで開きます。コマンドによるファイル変更はそのまま残ります。
- 設定で「ペット」「ペット＋数値」「数値のみ」を選択できます。数値表示はCPU / GPU / MEMそれぞれ「縦バー＋割合」のペアです。青・紫・オレンジのバーの高さが負荷を表し、数字の上に項目名が付きます。

## 計測と制約

- 全体CPUは全コア合計を100%とする差分値。初回は未計測の「—」です。
- 全体メモリはVM統計から、使用中ページ・圧縮メモリを加え、回収可能なファイルキャッシュ等を差し引く推定値です。Appleの表示と常に一致することは保証しません。
- GPUはIORegistryのドライバ提供値。M4 / macOS 15.8.1で取得を確認しました。この統計キーは安定した公開契約ではないため、未対応環境では「—」を表示します。複数GPUは最大値を採用します。
- バッテリー履歴は起動後から記録し、既存の「システム設定」の履歴を取り込みません。1分ごとに保存し、15分区間の最後の実測値を棒にします。スリープ等の欠測を埋めません。電池のないMacでは「バッテリーなし」と表示します。
- 2秒ごとに全体を更新。プロセス一覧の収集・表示は行いません。犬は2〜10fpsで、OSの「視差効果を減らす」設定では停止します。
- GlassはmacOS標準の`NSVisualEffectView`を使用します。macOS 15で動作する半透明表現であり、macOS 26専用のLiquid Glass APIは使用していません。

## 一時ターミナル

SwiftTerm 1.20.0（MIT）でローカルPTYと`/bin/zsh -f -i`を接続します。ユーザーの`.zshrc`を読み込まないクリーンなセッションで、コマンド履歴を保存しません。通常のzshプロファイルに定義したalias等は引き継ぎません。

パネルを閉じると、そのPTYのセッション内のジョブとシェルを終了します。自らセッションを離れたデーモンまでの終了は保証しません。継続させたい長時間処理には通常のターミナルを使用してください。

## 保存先

- 設定：`dev.local.menupup`のUserDefaults。
- 電池履歴：`~/Library/Application Support/MenuPup/battery.json`。直近48時間を保持。
- 通常動作ではターミナル出力をファイルに保存しません。

## 検証

Xcode本体のテストフレームワークに依存せず、Command Line Toolsで実行できます。

```sh
swift run MonitorChecks
swift run MenuPup --probe
./scripts/build.sh
open -n build/MenuPup.app --args --ui-checks "$PWD/outputs/ui"
```

最後のコマンドは専用設定と出力先でアプリを起動し、ステータス項目、テーマ・明暗、犬のフレーム切り替え、PTYでの実行、Ctrl-C、閉じるときの子プロセス終了、再オープンの初期化を自動操作します。結果は`outputs/ui/ui-checks.json`、画面は同ディレクトリのPNGに保存します。終了後にアプリも終了します。通常起動とは独立しています。

調査根拠・設計判断は[docs/research.md](docs/research.md)、検証結果は[docs/validation.md](docs/validation.md)を参照してください。

## キャラクター

Annoying DogはUNDERTALEのキャラクター（Toby Fox）です。[公式ページ](https://undertale.com/alarmclock/)と選定した生成案をもとに、A · Classic／B · Low Runの透過PNGを同梱しています。各4フレーム。高さ22ptの枠で比率を保ち、BはAより横幅を広く取ります。CPU負荷に応じて2〜10fpsで走ります。原作のスプライトそのものを同梱したものではありません。

生成画像は比較用の検証画像ではなくアプリが実行時に読む素材のため、`Sources/MenuPup/Resources/Pets/`でGit管理しています。生成方法とプロンプトは[docs/pet-assets.md](docs/pet-assets.md)を参照してください。

簡易表示の設計と別案は[docs/menu-readouts.md](docs/menu-readouts.md)を参照してください。
