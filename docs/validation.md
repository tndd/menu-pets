# 動作確認

2026年10月20日、Apple M4 / 32GB / macOS 15.8.1 / Swift 6.2.4で実施。

## 結果

- Releaseビルド成功。`codesign --verify --strict build/MenuPup.app`成功。
- `open -n build/MenuPup.app --args --ui-checks ...`でLaunch Services経由の起動を確認。
- 実アプリ内のUI・PTY結合チェック：26項目すべて成功。
- MonitorChecks：5項目すべて成功（CPU差分、電池履歴保存と欠測、無効値除外、破損ファイル保全、実機計測）。
- CPU・GPU・メモリ・電池の実測取得を確認。プロセス一覧の計測・表示は削除済み。
- 検証終了後にアプリのプロセスが終了することを外側から確認。

## UI・端末で確認した内容

256pt幅、3つのメーター、格子付き電池グラフ、テーマ・明暗の設定メニュー、3つのメニューバー表示モードを確認。Glassの通常／展開状態とMaterialのライト表示をアプリのウィンドウからPNG取得して目視確認した。

Annoying Dogの4フレームが互いに異なること、実際のステータスボタンのフレームが時間で変わること、CPU使用率0〜100%が2〜10fpsへ対応することを確認した。OSの「視差効果を減らす」を有効にしている環境では、停止する設計。

初回EnterでPTYが起動して下方向に展開すること、実コマンド・ANSI色・Ctrl-C、バックグラウンドのsleep終了、再オープン時に変数・作業ディレクトリが初期化されることを確認した。最初のコマンドはzshのプロンプトを検出してから送信し、TTYの二重エコーを避けている。

結果JSONとPNGは`outputs/final-ui/`。生成物はGit対象外。チェックはAppKitの実コントロールのaction呼び出しと端末へのキーイベントで行う。外部からの物理マウス操作・日本語IMEの包括的検証は行っていない。ネイティブAppKitアプリなので、ブラウザ・Playwrightは使用していない。
