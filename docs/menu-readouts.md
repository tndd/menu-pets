# メニューバーの簡易表示

実装した形式は「縦バー＋割合」を3組並べる方式。CPUは青、GPUは紫、メモリはオレンジ。上に小さくCPU / GPU / RAMを付け、順序と色だけに頼らず判別できるようにした。数字が1桁・3桁に変わっても表示幅は114ptで固定する。未計測値は空のバーと「—」。ペットを併記する場合は、その左に選択中の犬を置く。

数値の描画は計測更新ごとに行い、走行アニメーションでは生成済みの画像を再利用する。ボタンの外観変更時に文字色を更新し、VoiceOverとツールチップには項目名と値を文字列で渡す。

## 別の候補

| 形式 | 向いている使い方 | トレードオフ |
|---|---|---|
| 縦バー＋数字（実装済み） | 3項目の現在値を常に読みたい | 約114ptを使う |
| 3本のバー＋1つの数字 | 犬を主役にして横幅を小さくしたい | 数字を出す項目をCPUなどに決める必要がある |
| 数字の下に短い横バー | 文字中心で、グラフを控えめに添えたい | 高さの変化より負荷差が目立ちにくい |
| 小さな折れ線＋現在値 | 一時的な負荷と継続的な高負荷を見分けたい | 3項目すべてを並べると横幅を使う |

後の3案は提案段階で、設定項目としては追加していない。

数値表示では左右のボタン内余白を各2ptに指定し、数字を右揃えにして末尾の空きを抑えた。macOSの標準自動幅では左右各8ptだった。隣のアプリが確保する余白は変更しない。
